# Journal des modifications

## Version 2.0 — 08/11/2026
- Interface bleue épurée, typographie système Aptos / Segoe UI.
- Ajout multiple d'un exercice autorisé.
- RIR vide à chaque nouvel ajout.
- Commentaire individuel facultatif sous le tableau PDF.
- Recommandation générale facultative au début du PDF.
- Paramètres vides complètement absents du PDF.
- PDF sans date, heure, nom du site ou nom du praticien en tête ; signature unique en pied.
- Onglet programmes enregistrés : création, chargement, mise à jour, renommage, suppression.
- Sauvegarde JSON v2 compatible import v1, incluant les programmes enregistrés.
- Cache hors ligne reversionné.
