SAUVEGARDES

Mes données, sur mes appareils

Pas de synchronisation automatique : tu maîtrises tes sauvegardes.

↓

Exporter une sauvegarde

Crée un fichier .json avec ta bibliothèque, ses images et le programme en cours. Conserve-le dans Fichiers, sur une clé USB ou ailleurs.

↑

Importer une sauvegarde

Sur l’autre appareil, importe le fichier. Attention : l’import remplace les exercices et la sélection présents sur cet appareil.

Conseil de sécurité : sauvegarde régulièrement tes données. Les données locales peuvent être perdues si le navigateur efface le stockage, si l’application est supprimée ou si l’appareil est remplacé. Les fichiers ne sont pas chiffrés : évite d’y conserver des données identifiantes de patients.
MODE D’EMPLOI

Quelques gestes suffisent

Une application conçue pour fonctionner simplement, même sans connexion.

01

Créer une fiche

Dans Prescription, ajoute des exercices à droite. Renseigne le nombre de séries, de répétitions ou la durée, la charge, la pause, le RIR et les consignes. Clique sur « Créer le PDF » ; dans la fenêtre d’impression choisis « Enregistrer au format PDF » sur Windows, ou l’option de partage/enregistrement PDF sur iPad.

02

Ajouter un exercice

Dans Bibliothèque, choisis « Nouvel exercice ». Renseigne son nom, ses consignes et ses images, une étape à la fois ; les nouvelles images sont réduites en taille automatiquement pour économiser l’espace de stockage.

03

Utiliser hors ligne

Ouvre d’abord l’application une fois en ligne sur son adresse HTTPS, puis installe-la sur l’écran d’accueil. L’application et ses photos d’origine sont alors disponibles sans Internet, une fois mises en cache. Sous Windows, utilise « Installer l’application » dans Chrome ou Edge. Sur iPad : Safari → Partager → Sur l’écran d’accueil.

04

Transférer l’application d’un appareil à l’autre

Chaque appareil possède sa propre bibliothèque. Utilise Sauvegardes → Exporter sur le premier, puis Importer sur le second. Fais une sauvegarde avant chaque import important.

05

Garder l’application gratuitement

Les fichiers du projet sont fournis dans l’archive ZIP et peuvent être hébergés gratuitement sur une page HTTPS statique compatible, par exemple GitHub Pages. Tu conserves une copie de ton code et de tes données ; les conditions des hébergeurs gratuits peuvent évoluer.
