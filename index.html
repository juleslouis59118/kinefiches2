Transfert manuel entre appareils

Les données restent sur l’appareil utilisé, sans synchronisation automatique.

↓

Exporter

Enregistre la bibliothèque, les illustrations, les programmes préenregistrés et la fiche en cours dans un fichier JSON.

↑

Importer

Restaure le fichier sur un autre appareil. Les données présentes sur cet appareil seront remplacées après confirmation.

Important : fais une sauvegarde avant toute mise à jour importante. Les fichiers JSON ne sont pas chiffrés : ne stocke pas de noms de patients ni d’informations médicales identifiantes dans les commentaires ou les programmes.
AIDE

Mode d’emploi

Tout est prévu pour fonctionner sans Internet après la première installation.

01

Composer une prescription

Dans Prescription, ajoute des exercices autant de fois que nécessaire. Complète les séries, répétitions ou durée, le repos, la charge et le RIR. Laisse les champs inutiles vides : ils n’apparaîtront pas dans le PDF.

02

Ajouter une recommandation ou un commentaire

Renseigne « Recommandation générale » juste au-dessus de « Fiche en cours » si besoin. Dans chaque exercice, la zone « Commentaire » apparaît sous les paramètres du PDF uniquement si elle est remplie.

03

Enregistrer un programme type

Une fois la fiche composée, clique sur « Enregistrer ce programme ». Dans « Mes programmes », sélectionne « Utiliser » pour retrouver les exercices et paramètres. Tu peux créer plusieurs programmes et les renommer.

04

Créer un PDF

Clique sur « Créer le PDF ». Le fichier PDF est téléchargé directement. Sur Windows, retrouve-le dans Téléchargements ; sur iPad, retrouve-le dans Fichiers → Téléchargements. Aucun compte n’est nécessaire.

05

iPad, Windows et hors connexion

Ouvre une fois le site HTTPS en ligne sur chaque appareil. Sur iPad, ouvre Safari puis Partager → Sur l’écran d’accueil ; sur Windows, installe le site comme application dans Edge. Vérifie ensuite hors ligne. Chaque appareil dispose de son propre stockage.

06

Sauvegarder et transférer

Dans Sauvegardes, exporte un fichier JSON puis importe-le sur l’autre appareil. Cela inclut tes images et programmes préenregistrés. Ne confonds pas la sauvegarde JSON avec le PDF destiné au patient.
